# Task 03 – Banking Console Application (Python)

Console banking app: check balance, deposit, withdraw, exit. Opening balance ₹10,000.

## How to run
1. Install Python 3 (https://www.python.org/downloads/).
2. Open a terminal in this folder.
3. Run:
   - Windows: `python banking_app.py`
   - Mac/Linux: `python3 banking_app.py`
