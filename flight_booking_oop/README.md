# Flight Booking Console Application (Python, OOP)

Kiran Academy – Task 04.

## Run
    python main.py

## Structure
- `passenger.py` – abstract `Passenger`, `RegularPassenger` (0%), `StudentPassenger` (10%)
- `flight.py` – `Flight` with private fields and controlled seat reservation
- `booking.py` – `Booking` (stores a confirmed booking)
- `flight_booking_system.py` – menu, validation, fare calculation, booking
- `main.py` – entry point

## OOP concepts
Class/Object, Encapsulation, Inheritance, Polymorphism, Abstraction (ABC).
